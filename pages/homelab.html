AdGuard Home Setup March 2025

  • Basic statistics and filtering rules help keep the home network a little quieter and faster.

Discord Bot Container April 2025

  • Installed Node.js v20 via nvm and cloned the bot's repo from GitHub.
  • Used .env to manage API keys and secrets, then launched the bot with pm2.
  • The bot serves simple commands like /randomplayer and is monitored for uptime and logs.
